# Youth Literacy Gender Parity Dashboard

An interactive Streamlit dashboard analysing the Gender Parity Index (GPI) 
for youth literacy (ages 15–24) across 217 economies from 1970 to 2022.

**Dataset:** World Bank Gender Statistics — Literacy rate, gender parity index (youth ages 15–24)  
**Source:** https://data360.worldbank.org/en/indicator/WB_GS_SE_ADT_1524_LT_FM_ZS  
**Author:** Vishud Perera (w2055134) — 5DATA004C, University of Westminster

## Features
- 🗺️ Interactive world choropleth map
- 📈 Country trend analysis over time
- 🏆 Country rankings (highest/lowest GPI)
- 🌍 Regional aggregate comparison

## How to Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
